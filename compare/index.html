When this package is the right tool

sync-directory is a Node-local folder mirror: same machine, two paths, optional watch. It is not a remote deploy tool and not a backup system.

Copy vs hardlink inside this library

Choose copy when another process watches the target (dev servers, bundlers). Choose hardlink when you want speed and both trees live on the same volume. Hardlinks share inodes; some watchers never emit a change on the target file.
