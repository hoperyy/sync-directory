    A little context

    How to convert VTT to SRT

    1. Choose a .vtt file beginning with WEBVTT.
    2. Convert to SRT and review the warning list.
    3. Download the result and inspect it in the player or platform you plan to use.

    What changes in your file

    SRT does not represent WebVTT regions, cue positioning, CSS styles or voice and language tags in the same way. Caption Lab discards layout settings and WebVTT-specific markup during this conversion. It preserves basic b, i and u text tags; the destination platform may ignore those tags.

    VTT:  00:01.000 --> 00:03.500
SRT:  00:00:01,000 --> 00:00:03,500

    Format references

    For browser captions, read the WebVTT specification. For uploads, check YouTube’s supported subtitle formats. Different players can render the same file differently.

    Useful to know

    What happens to STYLE, NOTE and REGION blocks?

    They are omitted in the exported SRT. A warning appears when these blocks are detected.

    Will SRT look exactly like the VTT?

    Timing and text remain, but appearance can change because SRT cannot carry all WebVTT layout and styling.

    Can I use the SRT on YouTube?

    YouTube documents basic UTF-8 SRT support. Test the captions in your upload workflow; styling is not recognized in its basic SRT format.
