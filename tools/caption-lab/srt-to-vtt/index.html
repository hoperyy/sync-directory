    NOTES FROM THE EDIT DESK

    How to convert SRT to VTT

    1. Open a UTF-8 .srt file or paste its contents below.
    2. Choose Convert to VTT. The tool parses every cue before producing an output.
    3. Check the preview and download your .vtt file. Try it with your target video player.

    What changes in your file

    SRT uses numbered cues and comma-separated milliseconds. WebVTT starts with WEBVTT and uses a dot before milliseconds. This converter keeps cue timing, text and basic formatting while producing a new file. It does not create subtitles from video.

    SRT:  00:00:01,000 --> 00:00:03,500
VTT:  00:00:01.000 --> 00:00:03.500

    Format references

    Read the WebVTT specification and YouTube’s supported subtitle formats. Different players can render the same file differently.

    Useful to know

    Will my subtitles be uploaded?

    No. Conversion happens in your browser. Your selected file is read locally.

    Does this change subtitle timing?

    No. Conversion keeps the start and end of each cue. Use Shift subtitles if you need a timing offset.

    Is this a complete WebVTT editor?

    No. It generates a basic caption file. Advanced positioning, regions and styling need a dedicated editor.
