    A little context

    How to adjust subtitle timing

    1. Load your SRT or VTT file and find a line whose correct timing you know.
    2. Enter the offset in seconds. +2 delays all cues by two seconds; -2 makes them earlier.
    3. Apply the offset, review the output and download in your chosen format.

    What changes in your file

    A constant offset moves the whole subtitle timeline equally. It works when the mismatch stays the same throughout a video. If captions gradually drift, you need frame-rate conversion or two-point synchronization in a subtitle editor. This tool rejects an offset that would move any cue before zero rather than silently clipping it.

    Original: 00:00:05,000 --> 00:00:07,000
Offset:   -2 seconds
Result:   00:00:03,000 --> 00:00:05,000

    Format references

    For browser captions, read the WebVTT specification. For uploads, check YouTube’s supported subtitle formats. Different players can render the same file differently.

    Useful to know

    Should I use a positive or negative offset?

    Use a positive value when captions appear too early. Use a negative value when they appear too late.

    Does this fix progressive drift?

    No. It changes only a constant offset; the cue durations and spacing remain the same.

    Will WebVTT positioning be preserved?

    No. This first version exports basic text cues and omits positioning, region definitions and CSS styles. Keep your original file.
