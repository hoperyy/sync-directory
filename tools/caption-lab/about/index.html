Behind the tools

About Caption Lab

Caption Lab helps video creators, educators and editors convert and inspect text subtitles without installing a desktop editor. We focus on small, practical jobs: changing file formats, extracting text and correcting a constant timing offset.

Built and maintained by hoperyy

This is an independent project. Its source is maintained in a website workspace by hoperyy. The calculations and file transformations run in your browser. No account is required.

A focused first version

The current version handles UTF-8 SRT and basic WebVTT files up to 5 MB. It does not transcribe audio, translate captions, burn subtitles into video, or preserve advanced WebVTT layout. Read the notes next to each tool before exporting.

The tools are free today. If ads or paid services are introduced, the privacy information and product descriptions will be updated before those services launch.
