    A little context

    What this subtitle checker tests

    1. Open a UTF-8 SRT or VTT file.
    2. Run the checker. Invalid timing or missing cue text stops the export.
    3. Review timing and readability warnings, edit the source and check it again.

    What changes in your file

    The checker flags lines over 42 characters and reading speed over 20 non-whitespace characters per second as review prompts. These are adjustable editorial choices in real caption workflows, not universal accessibility standards. Overlapping cues can be intentional. A successful parse does not certify compliance with YouTube, Netflix or another platform.

    Checks: timestamp syntax · end after start
Review: cue order · overlaps · line length · reading speed

    Format references

    For browser captions, read the WebVTT specification. For uploads, check YouTube’s supported subtitle formats. Different players can render the same file differently.

    Useful to know

    Does it automatically fix every issue?

    No. It exports normalized numbering and timestamp formatting. You decide how to fix overlaps, timing and wording.

    Why is an overlap only a warning?

    Multiple speakers or on-screen text can legitimately overlap. Review the video before changing cues.

    Does it certify accessibility?

    No. Caption quality also depends on accuracy, speaker identification, sound descriptions and synchronization with the video.
